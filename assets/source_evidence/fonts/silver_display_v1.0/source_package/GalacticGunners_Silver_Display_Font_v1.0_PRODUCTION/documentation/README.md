# Galactic Gunners Silver Display v1.0

+An original angular industrial display type system derived from the supplied Galactic Gunners silver-word visual language. The installable font contains clean monochrome outlines; the silver, bevel, extrusion and glow are supplied as scalable frontend/rendering treatments.

+## Coverage
+
+- A–Z uppercase
+- a–z mapped deliberately to display capitals
+- 0–9
+- core punctuation, operators, €, £, $, %, &, @
+- OpenType kerning for prominent display pairs
+
+## Use
+
+- Install `desktop/*.otf` or `desktop/*.ttf`.
+- Copy `web/*` into the frontend and import `galactic-gunners-silver.css`.
+- Use `.gg-silver` for reliable UI text and `.gg-silver-cinematic` for enhanced live headings.
+- Use `cinematic/gg_silver_cinematic_GALACTIC.svg` for the scalable hero-title treatment.
+
+The 4K transparent PNG is a production reference/rendered title asset; it is not the font itself. Do not use cinematic glow for body text.
