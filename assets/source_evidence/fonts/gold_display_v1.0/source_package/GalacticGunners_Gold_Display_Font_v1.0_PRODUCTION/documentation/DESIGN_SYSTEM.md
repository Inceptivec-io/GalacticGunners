# Gold material system

+Face: hot gold alloy (#FFB000)
+Highlight: pale yellow-gold (#FFF2A2)
+Mid-bevel: orange (#F06A00)
+Recess: oxide red (#6B1000)
+Extrusion: brown-black (#210400)
+
+Construction uses broad angular strokes, clipped terminals and sharp mitred joins. Cinematic treatment is deliberately separated from glyph outlines so lettering remains searchable, selectable and scalable in the frontend.
