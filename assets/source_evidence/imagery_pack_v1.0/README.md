# Galactic Gunners: Final Assault™ — Imagery Pack v1.0 PRODUCTION

Complete 88-item visual estate built against the supplied creative brief and player/alien platform references.

## Runtime structure

- `brand/`: title lockups and icon masters
- `backgrounds/`: 4K campaign and state backgrounds
- `boarding/`: modular backgrounds, tiles, transit, props, pickups, VFX and HUD
- `ui/`: blank-value panels ready for runtime text/value overlays
- `buttons/`: separate normal and illuminated active states
- `marketing/`: key art, banners, store/press surfaces and screenshot frame
- `optional/`: transition, loading, mode and event surfaces
- `source/`: editable SVG logo and high-resolution visual masters
- `register/`: completed asset register
- `previews/`: contact sheets

## Runtime notes

- Full backgrounds are 3840×2160 unless the target surface requires another aspect ratio.
- Modular boarding tiles use a 256 px cell denominator and may be downscaled to the game's chosen grid.
- Boarding effects are 8-frame horizontal sheets with 256×256 cells.
- Dynamic UI fields are intentionally blank for live score, level, timer, reward and name data.
- Button `on` assets use unmistakable accent illumination; `off` assets retain the dark resting state.
