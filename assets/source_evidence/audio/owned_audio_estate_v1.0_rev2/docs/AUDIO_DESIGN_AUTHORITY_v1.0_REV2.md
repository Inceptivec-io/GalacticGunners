# Galactic Gunners Owned Audio Estate v1.0 REV2

Founder-approved design rule:

```text
GAMEPLAY EVENT SOUND
=
PHYSICAL / CINEMATIC EVENT REPRESENTATION

NOT
=
MUSICAL INTERPRETATION OF THE EVENT
```

Weapons sound like weapons. Impacts sound like impacts. Explosions sound like explosions. Hull destruction sounds like catastrophic structural destruction.

Only UI cues and Victory/Game Over stingers may intentionally use restrained tonal design.

Technical baseline: 48 kHz, 24-bit PCM stereo. No third-party recordings or commercial sample libraries.
