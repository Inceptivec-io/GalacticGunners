# Galactic Gunners Display v1.3 — PRODUCTION

Owner: **Inceptivec**

This production reissue supersedes the earlier v1.3 display-font outputs.

## Production normalization

The previous display pack had the same structural problem as the earlier title font: glyphs were not consistently normalized as one professional type family.

This release uses:
- one authoritative A–Z geometry source;
- one authoritative 0–9 geometry source;
- one visible cap height across the full family;
- one baseline;
- normalized sidebearings;
- preserved per-character width proportions;
- one silver/cyan material treatment sampled from the Founder-approved specimen.

No system-font fallback letters are used.

## Character coverage

- A–Z
- a–z codepoints mapped to matching uppercase display glyphs
- 0–9
- space
- `: - / ! ? . , + =`
