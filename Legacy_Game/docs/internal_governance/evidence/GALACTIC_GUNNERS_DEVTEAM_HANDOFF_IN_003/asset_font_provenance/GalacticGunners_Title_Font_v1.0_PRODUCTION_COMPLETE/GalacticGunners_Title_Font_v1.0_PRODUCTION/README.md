# GalacticGunners Title Font v1.0 — PRODUCTION

Owner: **Inceptivec**

This production reissue supersedes the earlier corrected pack.

## Production normalization

The prior pack mixed glyphs from differently scaled source rows. This release does not.

Every alphabetic glyph now uses one authoritative Galactic Gunners A–Z geometry family and every digit uses one authoritative 0–9 geometry family. The entire set is normalized to a common visible cap height, common baseline, consistent sidebearing policy, and one gold/orange material treatment sampled from the Founder-approved title artwork.

## Coverage

A–Z, a–z mappings, 0–9, space, `: - / ! ? . , + =`.

No system-font fallback letters are used.
