# GALACTIC GUNNERS — BOARDING ASSET SPECIFICATION REQUIREMENTS v1.0

Every Boarding asset pack must be derived from the approved runtime model.

For each asset require:

```text
ASSET ID
EXACT FILENAME
RUNTIME PURPOSE
MASTER DIMENSIONS
RUNTIME DIMENSIONS
FRAME DIMENSIONS
FRAME COUNT
FRAME ORDER
FPS / TRIGGER
FACING
ANCHOR / ORIGIN
COLLISION FOOTPRINT
TRANSPARENT PADDING
PALETTE
MATERIAL / SURFACE
LIGHTING
MODULAR CONNECTIONS
INTERACTION STATES
DAMAGE STATES
NEIGHBOUR ASSET RELATIONSHIPS
RUNTIME SCALE
CODE/SCENE CONSUMER
PROVENANCE
```

Minimum families:
- boarding player;
- alien crew;
- airlock;
- doors;
- corridors;
- platforms;
- cargo;
- reactor;
- engine room;
- weapons room;
- bridge;
- barrels/crates;
- loot;
- Boarding HUD;
- timer;
- health/hit bar;
- platform projectiles;
- hit/death effects;
- ship-destruction warning effects.

Art does not get created ahead of undefined mechanics.
