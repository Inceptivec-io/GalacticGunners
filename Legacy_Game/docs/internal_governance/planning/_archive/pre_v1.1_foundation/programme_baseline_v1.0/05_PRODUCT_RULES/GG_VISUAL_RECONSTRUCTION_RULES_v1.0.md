# GALACTIC GUNNERS — VISUAL RECONSTRUCTION RULES v1.0

The historical game is the reference for visual grammar and behaviour.

The current rejected first-pass IP Freedom visuals are defect evidence, not visual authority.

Commercial reconstruction must:
- remain faithful to original screen grammar;
- restore activity/flashing/animation;
- improve quality;
- use owned assets;
- preserve gameplay semantics;
- preserve shield tile mechanics;
- use owned arcade typography;
- pass Founder visual review in Docker.

No asset may dictate gameplay changes unless explicitly authorised.
