# GG-PROC-005 — IP / ASSET CHANGE PROCEDURE v1.0

For every commercial asset change:

1. identify source/creator;
2. identify rights basis;
3. classify;
4. record asset ID/path/hash;
5. identify superseded asset;
6. preserve creation/source evidence where owned;
7. integrate;
8. test;
9. update Asset Provenance Register;
10. update Dependency/Register debt if applicable.

Do not mark OWNED without evidence.
