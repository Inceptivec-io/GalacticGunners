# PRODUCT / VISUAL AUTHORITY MODEL

## Behaviour authority

The original/historical Galactic Gunners and legitimate preserved gameplay behaviour are the reference for how the game should behave.

Commercialisation must not erase original mechanics merely because a new asset requires integration.

## Visual authority

The current Founder-supplied `GalacticGunners_ASSETS.zip` is the primary current visual/font authority.

The implementation must visually align to:
- the supplied ships;
- projectiles;
- effects;
- backgrounds;
- logos;
- shield tile;
- UI icons;
- Game Over/Victory style panels;
- supplied font packages.

The previously Founder-rejected first-pass visual estate is not the target.

## Quality requirement

This is not a literal asset swap.

Development must produce a coherent commercial scene composition using the supplied assets and event-driven runtime UI.

The result must be materially higher quality than the Founder-rejected Docker build.

## No asset-led gameplay regression

Art integration does not authorise:
- loss of sprite animation;
- loss of shield destruction;
- changes to player lives;
- altered enemy behaviour;
- changed firing semantics;
- changed original progression.
