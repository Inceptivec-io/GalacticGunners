# IMPLEMENTATION NOTES

This pack contains actual replacement assets and replacement utility code.

## Important

- These assets are newly created for Galactic Gunners and are intended as the owned commercial replacement estate.
- They are not yet integrated into the game runtime.
- Integration must be performed through a governed handoff after GG-COM-001 closure.
- Keep current gameplay/hitboxes stable unless an asset mapping requires a bounded adjustment.
- Retain original MIT foundations (Phaser, Jared York-derived permitted code/sounds) unless a later decision explicitly replaces them.

## Runtime contents

- Sprite sheets: player, scout, cruiser, destroyer, boss, explosion, nuke
- Static sprites: asteroid, comet
- Backgrounds: 16:9, portrait, square
- UI icons: sound on/off, info, pause, resume, restart, controller, pointer
- Branding: wordmark/logo, symbol, menu titlecard, game-over, victory
- Audio: owned nuke SFX
- Utility replacements: align, grid, UI group

## Visual direction

90s arcade/console space-shooter memory with contemporary polish, clean silhouettes, current multi-device readability, and no photorealistic/cinematic overhaul.
