## Product-Owned / Modified Code

Original or substantially independently authored Galactic Gunners code is treated as proprietary product code. Derived code is treated as MIT-derived and modified, with upstream notice retained.

The repository must not contain a bare root MIT licence that accidentally represents the whole commercial product as MIT. The root LICENSE file states the product licence posture and preserves third-party exceptions through THIRD_PARTY_NOTICES.md.

## Media, Fonts and Utility Code

Legacy runtime art, fonts, the separate nuke/fireball sound and small tutorial/example utility code whose independent commercial provenance is not established are not falsely represented as commercial-release cleared. They are recorded for replacement through IP_FREEDOM_LICENSE_PROTECTION_ASSET_CREATION.
