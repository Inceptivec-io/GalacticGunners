# Boarding State Machine

`Shooter -> eligible hostile incapacitated -> physical approach -> Board or
Continue -> Boarding or target expiry -> preserved Shooter return`.

The runtime and server boundaries are implemented by
`game/src/boarding/BoardingStateMachine.ts`, `game/src/boarding/BoardingCoordinator.ts`
and `backend/boarding/`. F22 documentation admission does not itself certify the
ordinary-browser journey; that remains an H015 Final evidence gate.
