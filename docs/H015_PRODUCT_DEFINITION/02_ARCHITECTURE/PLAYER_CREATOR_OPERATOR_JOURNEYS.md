# Audience Journeys

| Audience | Journey | Product surface |
| --- | --- | --- |
| Player | Landing -> Start/Login -> Play -> Boarding -> result -> score/leaderboard -> replay | public shell and Phaser |
| Returning player | Login -> Command Post -> progress/scores -> Play | `/command-post` |
| Creator | Admin login -> Campaign -> Designer -> preview -> publish -> runtime | `/inceptivec-gamification-admin` |
| Operator/developer | Admin/System -> logs/users/build/docs/testing | protected admin and repository guides |

The exact Founder review journeys are preserved in the locked model. These paths
are traceability coordinates, not an automatic claim that every journey is closed.
