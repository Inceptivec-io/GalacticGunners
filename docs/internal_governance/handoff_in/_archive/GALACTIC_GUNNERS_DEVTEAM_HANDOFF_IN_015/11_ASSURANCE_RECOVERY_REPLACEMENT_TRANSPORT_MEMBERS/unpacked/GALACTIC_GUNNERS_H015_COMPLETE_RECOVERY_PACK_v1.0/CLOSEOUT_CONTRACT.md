# H015 Final Closeout Contract

The final return must be generated from machine-readable traceability and exact-SHA artifacts. It must report full local, remote, CI and runtime SHAs; clean worktree; draft/open/unmerged PR; test counts by classification and polarity; coverage/effectiveness results; browser/accessibility/security results; artifact IDs/hashes; all exceptions; and evidence links for every row.

`FOUNDER_REVIEW_READY=YES` is legal only when:

```text
CATALOGUE_REQUIREMENTS_TOTAL=50
CATALOGUE_REQUIREMENTS_PASS=50
CATALOGUE_REQUIREMENTS_FAIL=0
CATALOGUE_REQUIREMENTS_PENDING=0
CATALOGUE_REQUIREMENTS_UNACCOUNTED_FOR=0
ORDINARY_JOURNEYS_USING_FORCE_HOOKS=0
MANUALLY_ASSERTED_PASS_VALUES=0
TRACEABILITY_AUDIT=PASS
NEGATIVE_TEST_AUDIT=PASS
EVIDENCE_IDENTITY=PASS
EVIDENCE_UNIQUENESS=PASS
CROSS_BROWSER_ASSURANCE=PASS
ACCESSIBILITY_ASSURANCE=PASS
SECURITY_NEGATIVE_ASSURANCE=PASS
TEST_EFFECTIVENESS=PASS
CLOSURE_FAIL_CLOSED_PROOF=PASS
INDEPENDENT_TECHNICAL_REVIEW=PASS
PR_STATE=DRAFT_OPEN_UNMERGED
FOUNDER_ACCEPTANCE=PENDING
MERGE_PERFORMED=NO
```

No exemption may be invented. A genuine governed exception identifies authority, rationale, affected row and compensating evidence and still requires Founder approval before closure.
