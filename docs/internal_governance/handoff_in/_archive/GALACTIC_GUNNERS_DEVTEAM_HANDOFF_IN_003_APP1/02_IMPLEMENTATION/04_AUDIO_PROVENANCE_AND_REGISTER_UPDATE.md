Update the existing canonical Asset/IP Provenance Register rather than creating a competing register.

- canonical filename;
- runtime path;
- source = Founder-approved Galactic Gunners Owned Audio Estate v1.0 REV2;
- generation = original procedural synthesis;
- third-party recording = none;
- currentness = CURRENT;
- event mapping;
- replaced predecessor where applicable;
- SHA-256.

Also record:
- removed/superseded legacy sounds;
- retained legitimate sounds and why;
- any unresolved audio provenance item.
