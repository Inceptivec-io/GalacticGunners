# Repository Topology

The production repository is product-specific. CLOM engineering standards inform naming, currentness, boundary and execution rules; the CLOM repository tree is not copied as an application structure.

```text
apps/web/            Next.js product client
game/                Phaser/TypeScript game core
backend/             Django/DRF application authority
packages/contracts/  shared machine-readable interfaces
docs/                product/governance/documentation
Legacy_Game/         temporary legacy behavioural reference
```
