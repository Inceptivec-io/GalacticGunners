## Preservation doctrine

Existing legitimate gameplay behaviour is preserved unless a Founder-issued commission explicitly changes it.

No Worker/agent may:
- modernise for fashion;
- remove original behaviour because replacement assets are easier;
- infer gameplay changes from visual work;
- invent alternative score rules;
- redesign the game without explicit authority;
- treat automated PASS as Founder commercial acceptance.

## Quality doctrine

The commercial game must be:
- recognisably Galactic Gunners;
- materially better finished than the historical build;
- commercially presentable;
- faithful to the original;
- explainable and evidenced;
- owned/licensed correctly;
- playable across intended platforms;
- maintainable without destroying original design intent.

Founder visual/gameplay rejection overrides automated technical PASS.
