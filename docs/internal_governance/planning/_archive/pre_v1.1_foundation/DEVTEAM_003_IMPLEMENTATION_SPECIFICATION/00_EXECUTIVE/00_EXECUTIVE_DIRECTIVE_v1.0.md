# EXECUTIVE DIRECTIVE v1.0

## Authority

The Founder-supplied asset archive is now the visual authority for the current Galactic Gunners reconstruction movement. Development must align to these actual assets and supporting font packages rather than improvising style.

## Core rules

1. The uploaded assets are the style authority for current integration.
2. The historical game remains the behaviour and screen-grammar authority.
3. The previously rejected first-pass Docker build remains defect evidence only.
4. Any surface requiring interaction or live values must use event-driven runtime elements.
5. Title, Victory and Game Over are composed scenes, not single flattened posters.
6. The shield remains a destructible tile matrix, not a one-image bunker.
7. The supplied fonts must replace generic browser/system-font presentation.
8. Development must continue on the existing branch unless Founder explicitly changes branch policy.

## Event-driven rule

The following must not be baked irreversibly into a single static image when their state is interactive or variable:
- buttons;
- button hover/focus/selection states;
- counters;
- scores;
- level / stage labels;
- replay counts;
- nuke counts;
- lives counts;
- sound on/off state;
- pause/resume state;
- touch-selection feedback;
- leaderboard values;
- any title-screen selectable menu items.

Static art may provide:
- ornamental frames;
- decorative panels;
- scene branding;
- background shells;
- thematic overlays.

But dynamic values and interactive affordances must be rendered or controlled by code.
