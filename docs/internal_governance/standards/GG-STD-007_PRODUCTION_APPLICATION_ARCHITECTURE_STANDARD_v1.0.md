# GG-STD-007 Production Application Architecture Standard v1.0

**Status:** CURRENT / PROPOSED FOR DEV ADMISSION

Galactic Gunners shall use explicit product boundaries: Next.js product client, Phaser/TypeScript game core, Django/DRF authoritative backend, PostgreSQL data authority and versioned contracts. The browser is untrusted. Architecture changes must update affected guides, contracts, tests, currentness and diagrams in the same bounded change.
