# GG-PROC-003 — HANDOFF RETURN PROCEDURE v1.0

1. Confirm commissioned work complete or blocker explicit.
2. Confirm tests/evidence complete.
3. Update all registers.
4. Create:
   `docs/internal_governance/handoff_out/_archive/<HANDOFF_OUT_ID>/`
5. Assemble:
   - HANDOFF_OUT report;
   - file inventory;
   - evidence manifest;
   - test results;
   - final state record.
6. Package if required.
7. Calculate final SHA-256.
8. Seal.
9. Register sealed object.
10. Route to Founder through authorised exchange.
11. Remove transient routed copy from POST_BOX after receipt/placement.
12. Verify POST_BOX clean.
